# 打工系统

在山吹面包房、羽泽咖啡店、RiNG 咖啡厅三个地点新增打工玩法。

## 一、本体修改

| 文件 | 改动 | 说明 |
|------|------|------|
| `src/core/constants.ts` | 新增 `job: '打工'` | 行动标签的中文映射 |

| `src/content/core/index.ts` | 导入并注册 jobs | 核心 mod 加载时注册打工内容 |

## 二、三个店铺规则

### 山吹面包房（次结）

| 地点 | 城市 → 商店街 → 山吹面包房 |
|------|---------------------------|
| 时薪 | 1,200 円 |
| 结算 | 次结，即时到账 |
| 最低时长 | 1 小时 |

操作：点击「打工」→ 选择时长（1h / 2h / 4h / 8h）→ 时间跳过，薪水立即到账。

### 羽泽咖啡店（周结）

| 地点 | 城市 → 商店街 → 羽泽咖啡店 |
|------|---------------------------|
| 时薪 | 1,300 円 |
| 结算 | 周结（申请后满 7 天可领取） |
| 最低时长 | 2 小时 |
| 额外奖励 | 满 10 小时额外 +3,000 円 |
| 结算期限 | 14 天（第 8~21 天可领取） |

操作：
1. 点击「了解打工规则」→ 点击「申请打工」激活任务
2. 激活后出现 4 档时长按钮，选择时长打工
3. 打开任务面板查看进度
4. 满 7 天 + 满 2h → 点击「领取奖励」结算
5. 领取后可重新申请下一周

### RiNG 咖啡厅（周结）

| 地点 | 城市 → 车站前 → LiveHouse RiNG → RiNG 咖啡厅 |
|------|---------------------------------------------|
| 时薪 | 1,400 円 |
| 结算 | 周结（申请后满 7 天可领取） |
| 最低时长 | 2 小时 |
| 惩罚规则 | 不足 10 小时扣除 3,000 円 |
| 结算期限 | 14 天（第 8~21 天可领取） |

操作：同羽泽流程。结算时不足 10h 会扣 3,000 円，放弃或过期且不足 10h 同样扣除。

## 三、通用规则

- 三个店可以同时打工
- 已申请的任务不能重复申请（"申请打工"按钮自动隐藏）
- 满 7 天后打工按钮自动隐藏，必须结算后才能重新申请
- 存档/读档后任务进度保持一致
